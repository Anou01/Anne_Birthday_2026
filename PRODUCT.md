# A birthday for Ani
<!-- impeccable:product-schema 1 -->

## Platform
web

## Users and purpose
A private birthday surprise from the user to his girlfriend, Ani / ອານິ, for
30.9.2026. The experience is a personal gift, with a typed terminal introduction,
a candlelit cake, photographs, and the user's original Lao letter.

## Confirmed assets and direction
Use the supplied `cake/` and `letter/` models, `Bless.txt`, `Name.txt`, and photos.
The user chose a dimensional pink-and-white cake with soft lighting and one
candle, and explicitly instructed us to create a beautiful matching table.
Preserve all originals and the wording of the personal letter.

## Stack
Implementation choice: static HTML/CSS and native JavaScript, Three.js for the
models, and Vite for serving/building. No backend or account system is needed.

## Constraints
Touch and keyboard operation, responsive presentation, accessible text, optional
microphone with button fallback. Public deployment is not part of this build.
