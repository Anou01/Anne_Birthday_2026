# A birthday for Ani

เว็บวันเกิด 30.9.2026 ใช้โมเดลเค้กและจดหมายที่คุณเตรียมมา พร้อมโต๊ะไม้ที่สร้างขึ้นสำหรับฉากนี้

## เปิดเว็บในเครื่อง

ต้องมี Node.js รุ่นที่รองรับ Vite 8 (เครื่องนี้ตรวจแล้วว่าใช้ Node 24.14.1)

```powershell
npm install
npm run dev
```

เปิด URL ที่ terminal แสดง (ปกติ `http://127.0.0.1:5173/`)
ดูฉากโต๊ะโดยตรงที่ `http://127.0.0.1:5173/?scene=cake`

## สิ่งที่ทำได้

- หน้าแรก พร้อมวันที่และปุ่ม Enter
- ข้อความ Terminal ทยอยพิมพ์พร้อมเสียง กด Enter เพื่อแสดงทั้งหมด แล้วกดอีกครั้งเพื่อไปต่อ
- โต๊ะไม้ทรงกลม เค้กจากไฟล์ต้นฉบับ เทียนหนึ่งเล่ม และโมเดลจดหมาย
- กดโมเดลจดหมายหรือปุ่มเปิดจดหมายเพื่ออ่านข้อความจาก `Bless.txt`
- เป่าเทียนด้วยปุ่ม หรือเปิดไมค์เพื่อตรวจเสียงเป่า
- เค้กแยกเปิดตามรูปทรงแต่ละชั้น รูปคู่ค่อย ๆ เลื่อนขึ้นมา และเปิดแกลเลอรีได้ครบ 13 รูป
- ปิดเสียง ดูซ้ำ ใช้งานผ่านคีย์บอร์ด และรองรับ reduced motion

## ไฟล์ของคุณ

เก็บ `cake/`, `letter/`, `photo/`, `Name.txt`, `Bless.txt` ไว้เป็นต้นฉบับ
เว็บโหลดสำเนาที่เตรียมไว้ใน `public/assets/` และไม่ส่งรูปหรือเสียงไมค์ไปบริการภายนอก

หากแก้คำอวยพรหรือเปลี่ยนรูป ให้เตรียมสำเนาใหม่ด้วย Python ที่ติดตั้ง Pillow:

```powershell
python scripts/prepare_assets.py
```

สคริปต์จะคัดลอก `Bless.txt` โดยไม่แก้ข้อความ แยกเฉพาะไฟล์โมเดลที่ต้องใช้จาก ZIP
และสร้างรูป WebP สำหรับเว็บ โดยไม่แก้รูปต้นฉบับ
ชื่อ Ani ถูกใส่ในข้อความหน้าเว็บแล้ว; หากเปลี่ยนผู้รับให้แก้ `index.html` และ `src/main.js` ด้วย

## สร้างไฟล์สำหรับนำไปโฮสต์

```powershell
npm run build
npm run preview
```

ไฟล์ที่พร้อมนำไปโฮสต์อยู่ใน `dist/` ยังไม่ได้เผยแพร่สู่สาธารณะ
ต้องเปิดผ่านเว็บเซิร์ฟเวอร์ ไม่ใช่ดับเบิลคลิกไฟล์ HTML

## ตรวจสอบ

```powershell
npm test
node scripts/verify-browser.mjs
```

ชุดตรวจเบราว์เซอร์ต้องมี Chrome และมี dev server ทำงานที่พอร์ต 5173
หากตรวจ production preview ใช้ `$env:TEST_URL = 'http://127.0.0.1:4173'` ก่อนรัน
ตรวจกรณีไฟล์หายด้วย `node scripts/verify-fallbacks.mjs` (ค่าเริ่มต้นพอร์ต 4173)
ภาพและผลทดสอบอยู่ใน `.impeccable/review/`

ไมค์ทำงานผ่าน HTTPS หรือ localhost และต้องให้สิทธิ์ก่อน ระบบตรวจระดับเสียงที่ต่อเนื่อง
จึงอาจตอบสนองต่อเสียงอื่นด้วย ปุ่มเป่าเทียนใช้ได้เสมอ การตอบสนองต่อการเป่าจริงยังต้อง
ลองบนโทรศัพท์/ไมโครโฟนจริง การทดสอบอัตโนมัติครอบคลุมกรณีเปิดไมค์ไม่ได้
